# pic16f1459
rt-stepper dongle firmware for pic16f1459 8-bit microcontroller

### rt-stepper dongle
The rt-stepper dongle is a retired product from ecklersoft.com. The dongle was used to convert a parallel port CNC controller into a USB CNC controller. This version of the dongle was based on the pic16f1459.

### What's in this repository?
This repo contains source code that runs on the pic16f1459 8-bit microcontroller.
